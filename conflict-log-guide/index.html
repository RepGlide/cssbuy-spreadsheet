Conflict Log Guide

Record title, image, price context, option, and availability conflicts between the table and the page.

A conflict is a note, not a failure

When the table and the page disagree, write both down. The point is to keep the mismatch visible, not to pick a winner on the spot.

Title

If the page title differs from the row label, record both. A changed title means the source may have changed.

Image

If the page image does not match the row, record both. The two views may be of different items.

Price context

If the currency or time differs from the table, record both. A price only means something in context.

Option

If a color, size, or version is missing or changed, record both. The option is not the same as before.

Availability

If the page no longer shows the item available, record it. Availability is current, not remembered.

A worked log

  1. Table: the row names a size.
  2. Page: the size is no longer selectable.
  3. Log: both are written down until confirmed.
